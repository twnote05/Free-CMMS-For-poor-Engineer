# HOWTO — ตั้งระบบ Stock อะไหล่ให้ใช้งานได้ 100%

ทำตามลำดับนี้ทีเดียวจบ ข้ามข้อไหนระบบจะพังตรงนั้นเสมอ — แต่ละข้อเขียนไว้ว่า **ทำไม**
ถ้าต้องหยุดกลางทาง หยุดหลังข้อ 5 ได้ (ระบบใช้งานได้แล้ว แต่ยังไม่มีของในคลัง)

ใช้เวลาประมาณ **40 นาที** ถ้ายังไม่มีข้อมูลอะไหล่ · **1–2 ชม.** ถ้าต้องย้ายข้อมูลเดิม

---

## 0. สิ่งที่ต้องมี

- บัญชี Google (ฟรีก็ได้) — ระบบทั้งหมดอยู่บน Google Sheets + Apps Script ไม่มีค่าเซิร์ฟเวอร์
- Google Sheet หนึ่งไฟล์ (ใช้ไฟล์เดิมที่มีข้อมูลอยู่แล้วได้ — ดูข้อ 3)
- อีเมลของทุกคนที่จะใช้ระบบ (ช่าง / หัวหน้าช่าง / วิศวกรปฏิบัติการ)
- แท็บเล็ตหรือมือถือสำหรับจุดจ่ายของ · เครื่องสแกนบาร์โค้ด (ถ้ามี)

---

## 1. วางโค้ดลง Apps Script

1. เปิด Google Sheet ที่จะใช้เป็นฐานข้อมูล
2. เมนู **ส่วนขยาย → Apps Script** (Extensions → Apps Script) จะเปิดแท็บใหม่
3. ตั้งชื่อโปรเจค (มุมซ้ายบน) เช่น `ระบบ Stock อะไหล่`
4. สร้างไฟล์ให้ครบ **5 ไฟล์ ชื่อตรงเป๊ะ**:

| ทำอะไร | ชื่อที่ตั้ง | เอาเนื้อหาจาก |
|---|---|---|
| วางทับไฟล์ `Code.gs` ที่มีอยู่แล้ว | `Code.gs` | [Code.gs](../src/Code.gs) |
| กด **+ → Script** | `Auth` | [Auth.gs](../src/Auth.gs) |
| กด **+ → Script** | `Data` | [Data.gs](../src/Data.gs) — **ข้อมูลอะไหล่ 997 รายการฝังไว้แล้ว** |
| กด **+ → HTML** | `Index` | [Index.html](../src/Index.html) |
| กด **+ → HTML** | `App.js` | [App.js.html](../src/App.js.html) |
| กด **+ → HTML** | `Admin.js` | [Admin.js.html](../src/Admin.js.html) |

> `Data.gs` ใหญ่ประมาณ 187 KB (ข้อมูลจริงทั้งคลัง) วางแล้วรอสักครู่ให้ editor บันทึกเสร็จ
> ถ้าไม่วางไฟล์นี้ ระบบยังติดตั้งได้ปกติ แค่ต้องคีย์อะไหล่เอง

> **ระวังจุดนี้ที่สุด** — ตอนสร้างไฟล์ HTML ให้พิมพ์ `App.js` **ไม่ต้องพิมพ์ `.html`**
> ระบบเติมให้เอง ถ้าพิมพ์เองจะได้ `App.js.html.html` แล้วหน้าเว็บจะขึ้นว่าหาไฟล์ไม่เจอ
> (โค้ดพยายามเดาให้สองแบบแล้ว แต่ตั้งชื่อถูกตั้งแต่แรกดีกว่า)

5. กด **Ctrl+S** ทุกไฟล์ → ต้องเห็น **6 ไฟล์** ในแถบซ้าย

**เช็ค:** เลือกฟังก์ชัน `runAllTests` ใน dropdown ด้านบน → **Run** → ดู Execution log
ต้องขึ้น `ALL TESTS OK` ถ้าขึ้นแดงคือวางโค้ดไม่ครบไฟล์ใดไฟล์หนึ่ง

## 2. สร้างตารางในชีต

1. เลือก `setup` ใน dropdown → **Run**
2. Google จะขออนุญาต — ครั้งแรกเท่านั้น:
   **Review permissions → เลือกบัญชีตัวเอง → ขั้นสูง (Advanced) → ไปที่ … (ไม่ปลอดภัย) → Allow**
   > คำเตือน "ไม่ปลอดภัย" ขึ้นเพราะสคริปต์นี้ไม่ได้ผ่านการรีวิวจาก Google — มันคือสคริปต์ของคุณเอง
   > ที่ต้องขอสิทธิ์อ่าน/เขียนชีตนี้และส่งอีเมลแจ้งเตือน
3. กลับไปดูที่ Google Sheet — จะมีชีตใหม่ขึ้นมา 12 ชีต **พร้อมข้อมูลจริงครบแล้ว**:

| ชีต | ได้อะไรมาเลย |
|---|---|
| `Parts` | **อะไหล่ 997 รายการ** — คัดซ้ำออกแล้ว พร้อม Location 613 · Level 922 · Min 744 · ตำแหน่งใช้งาน 472 |
| `Tools` | **เครื่องมือช่าง 94 รายการ** แยก 5 ทีม พร้อมผู้รับผิดชอบ |
| `Blades` | **ใบมีด 145 ใบ** พร้อมสถานะและอายุใช้งานที่ถอดจาก History เดิม |
| `Machines` | อักษรย่อเครื่องจักรจริง 22 ตัว |
| `Code_Master` | มาตรฐานออกรหัส 73 หมวด |
| ที่เหลือ | `Batches_FIFO` `Issues` `Stock_Moves` `Purchase_Orders` `Blade_Log` `Users` `Settings` (ว่างไว้รอใช้งาน) |

   (`Audit_Logs` และ `Batches_Archive` สร้างเองตอนถูกใช้ครั้งแรก)

   ดูข้อความสรุปที่เด้งขึ้นมุมขวาล่างของชีต — บอกว่าลงไปกี่แถว

**ไม่ต้องก๊อปวาง CSV อะไรทั้งนั้น** ข้อมูลถูกฝังอยู่ใน `Data.gs` แล้ว

`setup()` **ไม่ลบอะไรทั้งนั้น** ชีตที่มีอยู่แล้วจะถูกเติมเฉพาะคอลัมน์ที่ขาด รันซ้ำได้ทุกเมื่อ
(รันซ้ำทุกครั้งที่อัปเดตโค้ดเวอร์ชันใหม่ — คอลัมน์ใหม่จะถูกเติมให้เอง)

**ข้อมูลตั้งต้นลงเฉพาะชีตที่ยังว่าง** — พอเริ่มใช้งานจริงแล้ว รัน `setup()` ซ้ำกี่ครั้ง
ก็ไม่ทับของจริง ถ้าอยากล้างเริ่มใหม่: ลบแถวข้อมูลในชีตนั้นให้เหลือแค่หัวตาราง แล้วรัน `setup()` อีกครั้ง

## 3. ข้อมูลเดิม — ลงให้แล้ว ไม่ต้องทำอะไร

ข้อ 2 ลงข้อมูลจากชีต `Spare Part All` ให้ครบแล้ว: **อะไหล่ 997 · เครื่องมือ 94 · ใบมีด 145**
คัดซ้ำออกแล้ว (ตรวจทั้งแบบตรงตัวและแบบไม่สนตัวพิมพ์ใหญ่เล็ก — เหลือ 0 รายการซ้ำ)

**เช็ค:** เปิดหน้าเว็บ (ข้อ 4) แท็บ **คลังอะไหล่** → ต้องเห็นอะไหล่เต็มหน้า
และ**ต้องไม่มีแถบแดง "รหัสซ้ำ"**

### ยอดคงเหลือ — ลงให้แล้วเหมือนกัน

`setup()` รับยอดยกมาเข้าคลังให้ด้วย **570 รายการ · 6,257 ชิ้น**
เป็น batch เดียวชื่อ `GRN-OPENING`

ทำครั้งเดียวตอนคลังยังว่าง รัน `setup()` ซ้ำกี่ครั้งก็ไม่เพิ่มซ้ำ — กันสต๊อกเบิ้ล

> ⚠ **ยอดนี้เป็นของวันที่ export ชีต ไม่ใช่ของวันนี้**
> นับสต๊อกจริงให้เร็วที่สุดแล้วแก้ส่วนต่างที่ **นับสต๊อก & ตัดจำหน่าย**
> ระบบที่เริ่มด้วยตัวเลขผิด คือระบบที่ไม่มีใครเชื่ออีกภายในสัปดาห์แรก

**ต้นทุนว่างทั้ง 997 รายการ** — ชีตเดิมไม่มีคอลัมน์ต้นทุนเลย
มูลค่าสต๊อกจึงเป็น ฿0.00 — ไม่ใช่บั๊ก ค่อยใส่ตอนรับของเข้าจริงครั้งแรก

### ถ้าอยากแก้ข้อมูลตั้งต้น

แก้ในชีตเอาเลย ง่ายกว่าแก้ใน `Data.gs` มาก — ไฟล์นั้นมีไว้ตอนติดตั้งครั้งแรกเท่านั้น

### 89 แถวที่ยังใช้ไม่ได้

ดู `Parts_needs_fixing.csv` — เป็นแถวที่ไม่มีรหัส (เขียนว่า `ยังไม่เปิดรหัส`) ไม่มีชื่อรายการ
หรือรหัสซ้ำกับแถวก่อนหน้า ไม่ต้องรีบ: พอมีของเข้าค่อยกด **+ เพิ่มอะไหล่**
ให้ระบบออกรหัสใหม่ตามมาตรฐานให้

## 4. Deploy เป็นเว็บแอป

1. กลับไปแท็บ Apps Script → ปุ่ม **Deploy** (มุมขวาบน) → **New deployment**
2. ไอคอนเฟือง ⚙ ข้าง "Select type" → **Web app**
3. กรอก:
   - Description: `v1`
   - Execute as: **Me** (ตัวคุณ)
   - Who has access: **Anyone with Google account**
4. **Deploy** → ก๊อป **Web app URL** (ลงท้ายด้วย `/exec`) เก็บไว้ — นี่คือลิงก์ที่ทุกคนใช้

> **ทำไมตั้ง "Anyone with Google account" ได้ทั้งที่มีสิทธิ์หลายระดับ**
> เพราะสิทธิ์ในระบบนี้ไม่ได้อ้างบัญชี Google — ทุกคนเข้าด้วย **PIN** และเซิร์ฟเวอร์เช็คสิทธิ์
> จาก session ของ PIN นั้น คนที่มีลิงก์แต่ไม่มีบัญชีในชีต `Users` เข้าไม่ได้เลย

5. เปิด URL นั้น → ต้องเห็นหน้าล็อก 🔒 → ใส่อีเมลตัวเอง + ตั้ง PIN 4–8 หลัก → เข้าได้เลย
   (บัญชีแรกถูกสร้างให้เป็น `ENG` วิศวกรปฏิบัติการ โดย `setup()` แล้ว)

## 5. ตั้งผู้ใช้และ PIN — **ทำก่อนบอกลิงก์ให้ใครใช้**

แท็บ **หลังบ้าน → ตั้งค่าและผู้ใช้ → ผู้ใช้และสิทธิ์**

สิทธิ์ไล่ตามสายงานจริงของหน้างาน — ไม่มีระดับ "แอดมิน" ที่ไม่มีใครนั่งเฝ้า:

| สิทธิ์ | ให้ใคร | ทำอะไรได้ |
|---|---|---|
| **ช่าง** `TECH` | ช่างทุกคน | สแกนเบิกเอง · คืนของที่ตัวเองเบิก · ดูคลัง + บัตรสต๊อก · ติดตั้ง/ถอด/ส่งลับคมใบมีด · ดูทะเบียนเครื่องมือ · **แก้ข้อมูลหลักไม่ได้ และไม่เห็นราคา** |
| **หัวหน้าช่าง** `LEAD` | หัวหน้าแต่ละไลน์ | + รับเข้า · สั่งซื้อ · นับสต๊อก · ตัดจำหน่าย · แก้ข้อมูลอะไหล่/เครื่องมือ/ใบมีด · รายงาน · เห็นต้นทุน · จ่ายของแทนคนอื่น |
| **วิศวกรปฏิบัติการ** `ENG` | วิศวกรที่ดูแลระบบนี้ | + ผู้ใช้และสิทธิ์ · ค่าระบบ · ประวัติการแก้ไข · ปลดระวางใบมีด · เก็บกวาดข้อมูล |

1. **+ เพิ่มผู้ใช้** ทีละคน: อีเมล, ชื่อที่แสดง (ชื่อนี้ขึ้นเป็น "ผู้เบิก" บนใบเบิก), สิทธิ์
2. **ตั้ง `ENG` ไว้อย่างน้อย 2 คน** — ไม่มีแอดมินภายนอกมากู้ให้ ถ้าคนเดียวลืม PIN จะไม่มีใครแก้ค่าระบบได้
3. **กดปุ่ม `PIN` ตั้งรหัสให้ทุกคนทันที** — ถ้าปล่อยว่าง ใครที่รู้อีเมลนั้นยึดบัญชีได้ตอนเข้าครั้งแรก
   หน้าจอขึ้นแถบเหลืองเตือนจนกว่าจะตั้งครบทุกบัญชี
4. บอกลิงก์ + PIN ให้แต่ละคน (เจ้าตัวเปลี่ยน PIN เองได้ที่รูปโปรไฟล์มุมขวาบน)

**เช็ค:** ให้ช่างคนหนึ่งลองเข้า — ต้องเห็น 3 แท็บ (เบิกอะไหล่ / คลังอะไหล่ / เครื่องมือ & ใบมีด)
ไม่มีเมนูหลังบ้าน ไม่มีปุ่มแก้ข้อมูลอะไหล่ และไม่เห็นราคา

### 🔑 ทางออกฉุกเฉิน — ต้องมีคนจำไว้ได้อย่างน้อยหนึ่งคน

ถ้า **วิศวกรปฏิบัติการเข้าไม่ได้ทุกคน** (ลืม PIN / ถูกล็อก / เผลอปิดบัญชีตัวเอง):

1. เปิด Apps Script → ไฟล์ `Auth.gs` → หาฟังก์ชัน `emergencyResetPin`
2. แก้สองบรรทัดบนสุดในฟังก์ชันนั้นเป็นอีเมลและ PIN ใหม่ที่ต้องการ
3. เลือก `emergencyResetPin` ใน dropdown → **Run** → เข้าระบบด้วย PIN นั้น แล้วเปลี่ยนทันที

ทำได้เพราะรันจาก editor ระบบให้สิทธิ์สูงสุด และฟังก์ชันนี้ **ไม่อยู่ใน allowlist ของ API**
จึงเรียกจากเบราว์เซอร์ไม่ได้เลย — คนที่แก้โค้ดได้คือเจ้าของสเปรดชีตเท่านั้น ไม่ใช่ทุกคนที่มีลิงก์

## 6. ตั้งเครื่องจักร / หน่วยงาน

**ตั้งค่าและผู้ใช้ → เครื่องจักร / หน่วยงาน → + เพิ่ม**

`setup()` ใส่อักษรย่อเครื่องจักรของจริงไว้ให้แล้ว 22 ตัว ตาม legend ในไฟล์มาตรฐานของคุณ:
`EXT1–EXT3` `MIX1–MIX3` `UV01 UV02` `CS01 CS02` `XPE1 XPE2` `PDM1 PDM2` `CRH1 CHR2`
`SLM1 SLM2` `AP01–AP03` และ `CM01` (Common — ของที่ใช้ร่วมทุกเครื่อง)
เพิ่ม/แก้ได้ตามหน้างาน

**ทำไมสำคัญ:** ทุกใบเบิกต้องระบุปลายทาง นี่คือสิ่งที่ทำให้ได้รายงาน "ต้นทุนอะไหล่ต่อเครื่องจักร"
ซึ่งเป็นตัวเลขที่ใช้ตัดสินใจว่าเครื่องไหนควรซ่อมใหญ่หรือเปลี่ยน
(ช่องนี้พิมพ์ชื่อใหม่ลงไปตรง ๆ ได้ด้วย — ตอนตีสามจะได้ไม่มีอะไรมาขวางการซ่อม)

## 7. ตั้งค่าอะไหล่ให้ครบ — Min / Max / MOQ / ที่เก็บ

แท็บ **คลังอะไหล่ → แก้ข้อมูลอะไหล่** (หรือคีย์ลงชีตตรง ๆ)

| ช่อง | ใส่อะไร | ถ้าไม่ใส่ |
|---|---|---|
| **Min** | ถึงจำนวนนี้ = ต้องสั่ง (จุดสั่งซื้อ) | ระบบเตือนของใกล้หมดไม่ได้เลย |
| **Max** | เติมขึ้นไปถึงเท่าไร | ระบบใช้ `2 × Min` |
| **MOQ** | ขั้นต่ำที่ผู้ขายรับต่อครั้ง เช่น ซีลขายยกกล่อง 25 ตัว | ไม่ปัด สั่งเท่าที่ขาด |
| **ที่จัดเก็บ** | ชั้น/ช่อง เช่น `A1` `G2` `I3` | ช่างต้องเดินหาเอง |
| **ตำแหน่งใช้งาน** | ใช้ที่จุดไหนของเครื่อง เช่น `ชุดยกงาน` | ช่างต้องเดาว่าใช่ตัวเดียวกันไหม |
| **Level** | `A` ต้องมีเสมอ (ของนอก) · `B` หาในประเทศได้ · `C` ไม่ค่อยจำเป็น | ไม่มีผลกับการเตือน แต่ใช้จัดลำดับความสำคัญตอนสั่งของ |
| **Part No.** | ปล่อยให้ระบบออกรหัสตามมาตรฐานให้ (ดูล่าง) หรือใส่บาร์โค้ดจริง | สแกนไม่ติด ต้องพิมพ์ค้นชื่อ |

**ออกรหัสใหม่:** กด **+ เพิ่มอะไหล่** จะมีกล่อง "ออกรหัสตามมาตรฐาน Code SP V1" อยู่บนสุด
เลือก 4 ช่อง (กลุ่ม / การใช้งาน / Type / หมวดชนิด) → เห็นรหัส 17 ตัวที่จะได้ทันที → กรอกชื่อ → บันทึก
เลขลำดับ (Running) ถูกจองตอนกดบันทึก สองคนกดพร้อมกันจึงไม่ได้เลขซ้ำ
รายละเอียดโครงรหัส: [MIGRATION.md](MIGRATION.md)

**สูตรหา Min แบบเร็ว:** `ใช้เฉลี่ยต่อสัปดาห์ × จำนวนสัปดาห์ที่ผู้ขายส่งของ × 1.5`
ของที่เครื่องหยุดทั้งไลน์ถ้าขาด ให้คูณ 2 ตั้งหยาบ ๆ ไปก่อนได้ — เดือนหน้าดูรายงานแล้วปรับ

## 8. รับของเข้าครั้งแรก (ถ้ามี)

ยอดยกมาลงให้แล้วตอน `setup()` (ข้อ 3) ข้อนี้คือของที่ซื้อมาใหม่หลังติดตั้งระบบ

**หลังบ้าน → รับเข้า & สั่งซื้อ**

1. ผู้ขาย · เลขที่บิล · อ้างอิงใบสั่งซื้อ (ถ้ามี)
2. กรอกทีละบรรทัด: รหัส (หรือกด 📷 สแกน), จำนวน, ต้นทุน/หน่วย
   (วันหมดอายุใส่เฉพาะของที่มีอายุ — จาระบี น้ำมัน ยางซีล กาว)
3. อะไหล่ตัวที่ไม่เคยมีในระบบ → **+ เปิดรหัสอะไหล่ใหม่**
   ระบบออกรหัสตามมาตรฐานแล้วเติมลงบรรทัดให้เอง
4. **รับเข้าคลัง**

> สต๊อกในระบบนี้มีอยู่ได้ในรูป batch เท่านั้น — นี่คือเหตุผลที่ FIFO,
> ต้นทุนต่อเครื่องจักร, การคืนของ ทำงานได้ถูกต้องทั้งหมด

**เช็ค:** กลับไปแท็บ **คลังอะไหล่** → คงเหลือเพิ่มตาม · กางดูจะเห็น batch ใหม่

## 9. ทดลองเบิกหนึ่งใบ

1. แท็บ **เบิกอะไหล่** → สแกนบาร์โค้ด (หรือแตะการ์ดอะไหล่)
2. ปรับจำนวน → เลือกเครื่องจักร → ใส่เลขใบแจ้งซ่อมถ้ามี
3. **ยืนยันการเบิก** → **🖨 พิมพ์ใบเบิก** ให้คนรับเซ็น

**เช็คว่าทุกอย่างต่อกันจริง:**
- คลังอะไหล่ → คงเหลือลดลงตามที่เบิก
- **บัตรสต๊อก** ของอะไหล่ตัวนั้น → เห็นบรรทัดเบิก + คงเหลือวิ่ง และบรรทัดล่างต้องบอก "ตรงกัน"
- รายงาน (ช่วงวันนี้) → เห็นยอดเบิกตามเครื่องจักรและตามผู้เบิก
- ชีต `Issues` และ `Stock_Moves` → มีแถวใหม่ พร้อมชื่อผู้เบิกและบัญชีที่ทำรายการ

## 11. ติดตั้งบนเครื่องที่หน้าคลัง

## 11.5 เครื่องมือช่าง & ใบมีด

แท็บ **เครื่องมือ & ใบมีด** (ช่างเข้าได้ทุกคน)

### ใบมีด — บันทึกแค่ "เกิดอะไรขึ้นวันไหน" แล้วอายุคำนวณเอง

ของเดิมต้องพิมพ์ History เป็นข้อความยาวและบวกวันเอง ที่นี่กลับด้าน: กดปุ่มตามเหตุการณ์จริง
แล้วระบบนับวันให้ — อายุใบมีดจึงไม่คลาดเพราะลืมบวกเลข

| สถานะ | ปุ่มที่กดได้ | เกิดอะไร |
|---|---|---|
| **สำรอง** | ⬇ ติดตั้ง · ✂ ส่งลับคม · ✕ ใช้ไม่ได้ · 🗑 ปลดระวาง | ติดตั้งต้องระบุเครื่องและตำแหน่ง |
| **ติดตั้งอยู่** | ⬆ ถอดออก · ✂ ส่งลับคม · ✕ ใช้ไม่ได้ | ตอนถอด/ส่ง ระบบบวกวันที่ใช้จริงเข้าอายุรวมให้ |
| **ส่งลับคม** | ↩ รับคืนจากลับคม · ✕ ใช้ไม่ได้ · 🗑 ปลดระวาง | นับจำนวนครั้งที่ลับคมให้อัตโนมัติ |
| **ใช้ไม่ได้** | ✂ ส่งลับคม · 🗑 ปลดระวาง | — |

- **หนึ่งตำแหน่งมีใบมีดได้ใบเดียว** ถ้ามีใบอื่นติดตั้งอยู่ ระบบเตือนให้ถอดใบนั้นก่อน
  ไม่ใช่ทับลงไปเงียบ ๆ แล้วเหลือใบมีดผีอยู่ในระบบ
- ปุ่ม **ประวัติ** = ทุกเหตุการณ์ของใบนั้นพร้อมจำนวนวันและคนที่ทำ (แทน History ที่เคยพิมพ์มือ)
- **ปลดระวาง** ทำได้เฉพาะวิศวกรปฏิบัติการ
- ชิปด้านบนเป็นตัวกรองและตัวนับในตัว: กด "ส่งลับคม" เห็นทุกใบที่ยังอยู่ที่ร้าน

> **หมายเหตุเรื่องหน่วย** — ข้อมูลเดิมของคุณนับเป็น **วัน** ("Used for 45 days", "อายุใช้งาน / วัน")
> ระบบจึงนับวันให้อัตโนมัติจากวันติดตั้ง ไม่ต้องกรอกอะไรเลย
> ถ้าต้องการ **ชั่วโมงเดินเครื่องจริง** ต้องดึงจากระบบสถานะเครื่องจักร — บอกได้ จะต่อให้

### เครื่องมือช่าง — ทะเบียนว่าอะไรอยู่กับใคร

จัดกลุ่มตามทีม (ช่างซ่อมบำรุง / Slot / Ext / UV / Xpe) แต่ละรายการมี จำนวน · ผู้รับผิดชอบ ·
วันที่รับมอบ · ราคา · สถานะ (ใช้งาน / ชำรุด / ส่งซ่อม / สูญหาย / ปลดระวาง)

- หัวหน้าช่างขึ้นไปแก้ได้ ช่างดูได้
- ทุกการแก้ถูกบันทึกลง `Audit_Logs` พร้อมชื่อคนแก้และค่าก่อน-หลัง
  — ของหายแล้วสถานะเปลี่ยนเงียบ ๆ ไม่ได้
- ช่องค้นหาเดียวค้นได้ทั้งชื่อเครื่องมือ ชื่อคน และทีม

## 11.7 แท็กติดหน้าช่องเก็บอะไหล่ (บาร์โค้ด / QR)

แท็บ **หลังบ้าน → แท็กติดช่องเก็บ** (หัวหน้าช่างขึ้นไป)

รหัสของที่นี่เป็นตัวอักษรผสมตัวเลขและมีขีด (`60002022MIX2-0001`) **ทำ EAN-13 ไม่ได้**
ระบบจึงใช้ **Code128** ซึ่งรับทุกอย่างที่พิมพ์ลงช่อง Part No. ได้ และมี **QR** ให้เลือกด้วย

| เลือกอะไร | เมื่อไร |
|---|---|
| **บาร์โค้ด (Code128)** | มีเครื่องสแกนเลเซอร์ — เร็วที่สุด ยิงติดในระยะ 10–30 ซม. |
| **QR** | สแกนด้วยกล้องมือถือ — ทนรอยเปื้อนน้ำมันและรอยขีดข่วนกว่า อ่านได้แม้ลบเลือนบางส่วน |
| **ทั้งคู่** | ช่วงเปลี่ยนผ่าน หรือช่องที่ทั้งสองแบบต้องใช้ได้ |

**ใน QR มีแค่รหัสอะไหล่เปล่า ๆ ไม่ใส่ลิงก์** — สแกนแล้วได้ข้อความรหัสลงช่องสแกนของหน้าเบิกทันที
ถ้าใส่ลิงก์ มือถือจะเปิดเบราว์เซอร์ขึ้นมาแทนที่จะกรอกให้ ซึ่งช้ากว่าและใช้ไม่ได้ตอนเน็ตล่ม

### สองแบบของแท็ก

- **ป้ายอะไหล่** — ติดหน้าช่องที่ของตัวนั้นอยู่ พิมพ์ได้: โลโก้ · ชื่ออะไหล่ · 📍ช่องเก็บ ·
  รหัส (บาร์โค้ด/QR + ตัวเลข) · Min · เครื่องที่ใช้ — ติ๊กเลือกได้ว่าจะพิมพ์อะไร
- **ป้ายช่องเก็บ** — ป้ายชื่อชั้น/ช่องตัวใหญ่ (`A1`, `G2`, `I3`) สแกนแล้วได้รหัสช่อง
  ใช้ตอนนับสต๊อกเพื่อยืนยันว่ากำลังยืนอยู่ช่องไหน

### เลือกของขึ้นแผ่นได้ 4 ทาง

1. สแกนหรือพิมพ์รหัสทีละตัว
2. **เพิ่มทั้งช่อง** — เลือกช่องเก็บ ได้อะไหล่ทุกตัวในช่องนั้นทีเดียว (ทำป้ายใหม่ทั้งชั้นรอบเดียว)
3. **ที่ถึงจุดสั่งซื้อ** — เฉพาะตัวที่กำลังขาด
4. **ทุกตัวที่มีของในคลัง** — ตอนทำป้ายครั้งแรกทั้งคลัง

หรือกด **🏷️ พิมพ์แท็ก** ที่อะไหล่ตัวใด ๆ ในแท็บคลังอะไหล่ ระบบเด้งมาหน้านี้พร้อมตัวนั้นบนแผ่นแล้ว

### ขนาดกระดาษสติกเกอร์

| preset | ขนาดดวง | ต่อแผ่น | เหมาะกับ |
|---|---|---|---|
| A4 · 8 ดวง | 105×74 mm | 8 | ป้ายช่องใหญ่ อ่านจากระยะไกล |
| A4 · 12 ดวง | 105×48 mm | 12 | ป้ายช่องขนาดกลาง |
| **A4 · 24 ดวง** | **70×37 mm** | **24** | **ค่าเริ่มต้น — ป้ายอะไหล่ทั่วไป** |
| A4 · 40 ดวง | 48×25 mm | 40 | ของชิ้นเล็ก ช่องแคบ |
| A4 · 65 ดวง | 38×21 mm | 65 | เล็กสุด ใช้บาร์โค้ดอย่างเดียวดีกว่า |
| ม้วน 50×25 | 50×25 mm | 1 ต่อดวง | เครื่องพิมพ์ฉลากแบบม้วน |

**ตัวอย่างบนจอคือขนาดจริงเป็นมิลลิเมตร** ทุก preset ถูกวัดแล้วว่าลงตัวกับหน้า A4 (210 mm)
— ทดสอบครบทั้ง 6 ขนาด × 3 ชนิดรหัส ไม่มีดวงไหนล้นขอบ

### ก่อนพิมพ์แผ่นจริง — ทำครั้งเดียวจบ

1. **พิมพ์ลงกระดาษเปล่าก่อน** แล้วทาบกับกระดาษสติกเกอร์ส่องไฟดู
2. ถ้าเหลื่อม ใส่ค่า **ขยับแผ่น (มม.)** ขวา/ลง แล้วลองอีกครั้ง
3. พอตรงแล้วค่อยป้อนกระดาษสติกเกอร์จริง — เครื่องพิมพ์แต่ละตัวเพี้ยนไม่เท่ากัน
   ตั้งค่านี้ทีเดียวแล้วจำไว้ใช้ตลอด
4. ในหน้าต่างพิมพ์ ตั้ง **Margins = None** และ **Scale = 100%** (ห้าม "Fit to page" เด็ดขาด
   ไม่งั้นทุกดวงจะเลื่อนหมด)

## 11.8 สแกนด้วยกล้องมือถือ

ไม่มีเครื่องแฮนด์เฮลด์ก็สแกนได้ — ปุ่ม 📷 อยู่ใน 4 ที่:

| หน้า | สแกนแล้วได้อะไร |
|---|---|
| เบิกอะไหล่ | ใส่ตะกร้าเลย |
| นับสต๊อก | เข้ารายการนับทันที ไม่ต้องกด + เพิ่ม |
| ตัดจำหน่าย | เติมรหัสให้ แล้วกรอกจำนวนต่อ |
| รับเข้าคลัง | ทุกบรรทัด ยิงเข้าบรรทัดนั้นตรง ๆ |

อ่านได้ทั้ง **Code128 และ QR** ตรงกับที่แท็บแท็กพิมพ์ออกมา · เจอรหัสแล้วเครื่องสั่น

**รหัสที่ไม่มีในคลังจะไม่ถูกใส่ให้** — ขึ้นเตือนแทน กันสแกนกล่องผิดแล้วนับลงรายการมั่ว

### มีสองโหมด ระบบสลับให้เอง

- **กล้องสด** — เล็งค้างไว้ เจอแล้วปิดเอง
- **ถ่ายทีละใบ** — ใช้เมื่อกล้องสดเปิดไม่ได้

แอปรันอยู่ใน iframe ของ Apps Script ซึ่ง**เราคุมสิทธิ์กล้องของ iframe ไม่ได้** บางเครื่อง
บางเบราว์เซอร์จึงถูกบล็อก (เปิดผ่านแอป LINE เจอบ่อย) โหมดถ่ายทีละใบใช้ตัวเลือกไฟล์ของ
เครื่องจึงไม่ติดข้อจำกัดนี้ ระบบลองกล้องสดก่อน ล้มแล้วค่อยเสนอตัวสอง

> ตัวอ่านบาร์โค้ดโหลดตอนกดปุ่มครั้งแรกเท่านั้น (330 KB) ไม่ถ่วงตอนเปิดแอป
> ครั้งแรกเบราว์เซอร์จะถามสิทธิ์กล้อง — กดอนุญาต

## 11.9 รูปอะไหล่

การ์ดอะไหล่แสดง **รูปจริง** ถ้ามี · ยังไม่มีจะเป็น **ช่องสีที่ล็อกจากชื่อ** อะไหล่ตัวเดิม
ได้สีเดิมเสมอ — ช่างจำสีได้เร็วกว่าอ่านรหัส 17 หลัก

ทุกรายการมีปุ่ม **🔎 หารูป** ค้น Google รูปภาพจากชื่ออะไหล่ให้ (ไม่เอารหัสปน เพราะรหัส
เป็นรหัสภายใน ใส่ไปแล้วค้นไม่เจอ)

### ใส่รูปจริง — สองทาง

**ทาง A · ถ่ายจากมือถือ** (ทีละตัว สะดวกตอนอยู่หน้าชั้น)
คลังอะไหล่ → กางรายการ → **📷 ถ่ายรูป** → เปิดกล้องหลัง → ถ่าย → เข้าระบบทันที
มีในบัตรสต๊อกด้วย

รูปถูกย่อในเครื่องก่อนส่ง (ยาวสุด 1000px เหลือ ~150 KB จาก 3-8 MB) ถ้าส่งดิบจะช้ามาก
บนเน็ตโรงงาน และกินโควต้า Drive ฟรีหมดเร็ว

**ทาง B · ผูกทีเดียวทั้งคลัง** (เร็วกว่ามากถ้ามีรูปอยู่แล้ว)
ตั้งค่าและผู้ใช้ → 🖼️ รูปอะไหล่

1. ตั้งชื่อไฟล์ขึ้นต้นด้วยรหัสอะไหล่ — `60002048M006-0005.jpg`
   หรือ `60002048M006-0005 ปะเก็น.jpg` ก็ได้
2. โยนเข้าโฟลเดอร์ Drive เดียว → แชร์แบบ **ทุกคนที่มีลิงก์**
3. วางลิงก์โฟลเดอร์ → **ดึงรูปมาผูก**

ทยอยถ่ายแล้วกดซ้ำได้เรื่อย ๆ · รูปที่ผูกไว้แล้วไม่ถูกทับ เว้นแต่ติ๊ก "ทับรูปที่ผูกไว้แล้ว"

> โฟลเดอร์ที่ลืมแชร์ = รูปขึ้นเฉพาะเครื่องคุณ คนอื่นเห็นเป็น ⚠
> ครั้งแรกที่ใช้ Apps Script จะขอสิทธิ์ Drive เพิ่ม — กด Allow

**สิทธิ์:** หัวหน้าช่างขึ้นไป ตามกฎว่าช่างแก้ข้อมูลไม่ได้
อยากให้ช่างถ่ายเองได้ (คนที่ยืนอยู่หน้าชั้นคือช่าง) แก้คำเดียวใน `savePartImage`
จาก `'LEAD'` เป็น `'TECH'` — ทุกครั้งมี audit log ว่าใครอัป

## 11.10 เพิ่มหมวดชนิดใหม่ในระบบรหัส

ฟอร์ม **+ เพิ่มอะไหล่** → ช่องหมวดชนิด → ปุ่ม **+**

กรอกชื่อไทย/อังกฤษ กับอักษรย่อ 4 ตัว · Key 3 หลักระบบออกให้เอง · กลับมาฟอร์มเดิม
พร้อมเลือกหมวดใหม่ให้แล้ว ค่าที่กรอกค้างไว้ไม่หาย

### กันรหัสซ้ำสามชั้น

1. **อักษรย่อห้ามซ้ำ** ตรวจกับทุกหมวดที่มี ไม่สนตัวพิมพ์เล็กใหญ่ ชนแล้วบอกว่าชนกับหมวดไหน
2. **Key ออกจากตัวมากสุด + 1** ไม่ถมรูที่ว่าง เพราะเลขที่เคยออกไปอยู่บนสติกเกอร์แล้ว
   เอากลับมาใช้ใหม่คือการชนกันเงียบ ๆ
3. **อ่านและเขียนอยู่ใน lock เดียวกัน** สองคนกดพร้อมกันไม่ได้ Key เดียวกัน

ต่อให้หลุดทั้งสามชั้น รหัสอะไหล่ก็ยังไม่ซ้ำ เพราะระบบกวาดรหัสจริงทั้งคลังแล้วเอาเลขมากสุด + 1
ไม่ได้นับจากจำนวนแถวในหมวด

> อักษรย่อใหม่ที่บังเอิญตรงกับรหัสเก่านอกระบบ จะ**นับต่อจากของเดิม ไม่เริ่มที่ 0001**
> และเด้งข้อความบอก จะได้ไม่งงตอนเห็นรหัสแรกเป็น 0043

## 11.11 พื้นที่เก็บข้อมูล — เตือนก่อนเต็ม

Google Sheet หนึ่งไฟล์เก็บได้ **10 ล้านช่อง** พอเต็มแล้ว**เบิกไม่ได้ รับเข้าไม่ได้ทั้งระบบ**
ไม่ใช่แค่ประวัติหาย จึงต้องรู้ล่วงหน้า

**ดูในแอป:** หลังบ้าน → รายงาน & คืนของ → 💾 พื้นที่เก็บข้อมูล
แถบวัด + ตารางว่าชีตไหนกินที่สุด · เขียว → เหลือง 70% → แดง 85%

**ดูในอีเมล:** เกิน 70% อีเมลสรุปประจำวันจะมีหัวข้อพื้นที่เพิ่มมา · เกิน 85% ชื่อเรื่องขึ้น ⚠
ให้เห็นตั้งแต่ยังไม่เปิดอ่าน — คนที่ต้องรู้ไม่ได้เปิดแอปทุกวัน

### สำรอง & ตัดข้อมูลเก่า

ชีตที่ตัดได้ 4 ตัว เป็นบันทึกย้อนหลัง ไม่ใช่ยอดปัจจุบัน:
`Stock_Moves` · `Issues` · `Audit_Logs` · `Blade_Log`

เลือกว่าเก็บย้อนหลังกี่ปี (แนะนำ 1 ปี) แล้วระบบจะ:

1. เขียนแถวที่เก่ากว่านั้นเป็น CSV ลง Drive โฟลเดอร์ `สำรองข้อมูล - <ชื่อชีต>`
2. **เขียนไฟล์สำเร็จแล้วเท่านั้น** จึงลบออกจากชีต — เขียนพัง ไม่ลบอะไรเลย

**ยอดคงเหลือไม่กระทบ** เพราะยอดมาจาก batch ไม่ได้มาจากชีตพวกนี้
ที่หายคือความสามารถย้อนดูบัตรสต๊อกเกินช่วงที่เก็บ

`Parts` `Batches_FIFO` `Tools` `Blades` ตัดไม่ได้ ระบบปฏิเสธ — พวกนั้นคือสถานะปัจจุบัน

**สิทธิ์:** ดูได้ตั้งแต่หัวหน้าช่าง · **ตัดได้เฉพาะวิศวกร**

## 15. แก้ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| หน้าเว็บขึ้น "ไม่พบไฟล์ HTML App.js" | ตั้งชื่อไฟล์ผิด (มี `.html` ต่อท้าย) | สร้างไฟล์ HTML ชื่อ `App.js` เฉย ๆ แล้ว Deploy เวอร์ชันใหม่ |
| ขึ้น "ไม่พบชีต … รัน setup()" | ยังไม่ได้รัน `setup()` หรือชีตถูกเปลี่ยนชื่อ | รัน `setup()` |
| แก้โค้ดแล้วหน้าเว็บไม่เปลี่ยน | ยังใช้ deployment เวอร์ชันเดิม | **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** |
| เข้าระบบแล้วหลุดบ่อย | session หมดอายุ 12 ชม. (หนึ่งกะ) | ใส่ PIN ใหม่ ปกติ |
| ช่างเห็นเมนูหลังบ้าน | ตั้งสิทธิ์เป็น STORE/ADMIN | ตั้งค่า → ผู้ใช้ → แก้เป็นช่าง (มีผลตอนโหลดหน้าถัดไป) |
| เบิกแล้วขึ้น "ไม่พอ" ทั้งที่ของอยู่บนชั้น | ยังไม่ได้รับเข้าระบบ หรือของอยู่ใน batch ที่หมดอายุ | รับเข้า หรือตัดจำหน่ายของหมดอายุก่อน |
| คงเหลือในระบบไม่ตรงของจริง | มีคนหยิบไม่เบิก หรือแก้ชีตมือ | ดูบัตรสต๊อกหาบรรทัดที่หาย → นับสต๊อกปรับ |
| มูลค่าสต๊อกดูเบิ้ล | รหัสอะไหล่ซ้ำในชีต `Parts` | ลบแถวที่เกิน (แถบแดงบอกรหัสให้แล้ว) |
| สแกนแล้วไม่เข้าตะกร้า | เครื่องสแกนไม่ส่ง Enter หรือรหัสในชีตไม่ใช่บาร์โค้ดจริง | ตั้งเครื่องสแกนให้ส่ง CR · แก้ Part_No ให้ตรงบาร์โค้ด |
| พิมพ์ใบเบิกออกมาเพี้ยน | ความกว้างกระดาษไม่ตรง | ตั้งค่า → `ความกว้างใบเบิก` = 58 หรือ 80 ตามเครื่องพิมพ์ |
| อีเมลเตือนไม่มา | ยังไม่กดตั้ง trigger หรือไม่มีอะไรต้องเตือน | ตั้งค่า → `ตั้งอีเมลเตือน 08:00` (ไม่มีของใกล้หมด = ไม่ส่ง) |
| ระบบช้าลงเรื่อย ๆ | `Batches_FIFO` โตขึ้นมาก | ตั้งค่า → `ย้าย batch ที่หมดแล้ว` |
| **วิศวกรเข้าไม่ได้ทุกคน** | ลืม PIN / ถูกล็อก / ปิดบัญชีตัวเอง | รัน `emergencyResetPin` ใน Apps Script (ดูข้อ 5) |
| ติดตั้งใบมีดไม่ได้ ขึ้นว่าตำแหน่งมีใบอยู่ | ใบเดิมยังไม่ถูกถอดในระบบ | กด ⬆ ถอดออก ที่ใบเดิมก่อน |
| แท็กพิมพ์ออกมาเลื่อนทุกดวง | หน้าต่างพิมพ์ตั้ง Fit to page หรือ margin ไม่ใช่ None | ตั้ง Scale 100% · Margins None แล้วใช้ช่องขยับแผ่นแทน |
| สแกนแท็กแล้วไม่เข้าตะกร้า | รหัสบนแท็กไม่ตรงกับช่อง Part_No หรือเครื่องสแกนไม่ส่ง Enter | เทียบรหัสในชีต `Parts` · ตั้งเครื่องสแกนให้ส่ง CR |
| QR บนดวงเล็กสแกนไม่ติด | 38×21mm มีที่ไม่พอให้ QR ละเอียด | ใช้บาร์โค้ดกับดวงเล็ก หรือเปลี่ยนไป 70×37mm |
| รัน `setup()` แล้วชีต `Parts` ยังว่าง | ยังไม่ได้วางไฟล์ `Data.gs` หรือชีตมีข้อมูลค้างอยู่ | วาง `Data.gs` → ลบแถวใน `Parts` ให้เหลือหัวตาราง → รัน `setup()` ใหม่ |
| `seedOpeningStock` ขึ้นว่ามี batch แล้ว | ยอดยกมาถูกใส่ไปแล้วรอบหนึ่ง | ถูกต้องแล้ว — ถ้าจำนวนไม่ตรง ใช้การนับสต๊อกแก้ |
| อายุใบมีดดูน้อยกว่าจริง | เพิ่งย้ายข้อมูลเข้า อายุเก่าถอดจาก History ได้เท่าที่มีวงเล็บ (xx days) | แก้ `Days_Used_Total` ในชีต `Blades` ให้ตรงได้เลย |

## 16. เวลาอัปเดตโค้ดเวอร์ชันใหม่

1. วางโค้ดใหม่ทับไฟล์เดิมใน Apps Script → Ctrl+S
2. รัน `runAllTests` → ต้องขึ้น `ALL TESTS OK`
3. รัน `setup()` หนึ่งครั้ง (เติมคอลัมน์ใหม่ที่เพิ่มมา ของเดิมไม่หาย)
4. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**
5. บอกทุกคนให้กดปุ่ม ↻ ที่มุมขวาบนของหน้าเว็บ (หรือปิดเปิดแอปใหม่)
