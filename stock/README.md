# ระบบ Stock อะไหล่ — เทมเพลตสำหรับโรงงาน

[↑ หน้าแรกของ repo](../README.th.md) · ใช้คู่กับ [cmms/](../cmms/README.th.md) ได้ — ดู [SHARED-USERS.md](../SHARED-USERS.md)

ระบบ **เบิก–รับเข้า–นับสต๊อก** อะไหล่ เครื่องมือช่าง และใบมีด
ทำงานบน **Google Apps Script + Google Sheets** ล้วน ๆ ไม่มีเซิร์ฟเวอร์ ไม่มีค่ารายเดือน

ออกแบบจากหน้างานจริงของโรงงานพื้นไม้คอมโพสิต ที่ทีมเป็นช่างล้วน ไม่มีแผนก IT
เปิดจากมือถือ Android ราคาประหยัดบน Wi-Fi โรงงาน และ **สอนใช้ได้ใน 5 นาที**

> **English:** the user interface is Thai only. The engine, data model and API are
> documented in English in [docs/INTEGRATION.md](docs/INTEGRATION.md) if you want to
> build your own front end on top of it.

## ทำอะไรได้

| | |
|---|---|
| **เบิกของ** | สแกนรหัส → ใส่จำนวน → จบ · ตัดสต๊อกแบบ FEFO แล้ว FIFO ให้เอง |
| **รับเข้า** | สร้าง batch ใหม่พร้อมต้นทุนและวันหมดอายุ · ออกรหัสอะไหล่ใหม่ได้ในตัว |
| **นับสต๊อก** | นับจริงเทียบกับระบบ แล้วปรับส่วนต่างเข้า batch |
| **ตัดจำหน่าย** | ของเสีย ของหมดอายุ ของหาย — มีเหตุผลกำกับทุกครั้ง |
| **เครื่องมือช่าง** | ใครถืออะไรอยู่ แยกตามทีมช่าง |
| **ใบมีด** | ติดตั้งอยู่เครื่องไหน ลับคมไปกี่รอบ ใช้มากี่วัน |
| **รายงาน** | ของใกล้หมด ของนอน ของใกล้หมดอายุ มูลค่าสต๊อก ใบสั่งซื้อค้าง |
| **สแกน** | บาร์โค้ด/QR ด้วยกล้องมือถือ ถ้ากล้องสดถูกบล็อกจะถ่ายทีละใบให้แทน |
| **พิมพ์ใบเบิก** | เครื่องพิมพ์สลิปความร้อน 58 หรือ 80 มม. |

**สิทธิ์ 3 ชั้น** — ช่าง (เบิก/ดู) · เจ้าหน้าที่คลัง (รับเข้า/นับ/แก้ข้อมูล) · ผู้ดูแลระบบ (ทุกอย่าง)
เข้าระบบด้วย **PIN** ไม่ต้องมีบัญชี Google เพราะช่างใช้มือถือร่วมกัน

## ต้องมีอะไรบ้าง

- บัญชี Google หนึ่งบัญชี (ฟรีก็ได้) — **ไฟล์ชีตจะอยู่ในบัญชีนี้ ให้ใช้บัญชีของบริษัท**
- เวลาประมาณ 30 นาที
- ไม่ต้องลงโปรแกรมอะไร ไม่ต้องรู้โค้ด

## ติดตั้ง

**1. สร้าง Google Sheet เปล่า 1 ไฟล์** ตั้งชื่อตามใจ

**2. เปิด Apps Script** — ในชีต: ส่วนขยาย → Apps Script

**3. วาง 6 ไฟล์จากโฟลเดอร์ [`src/`](src/)** ชื่อในฝั่ง Apps Script **ต้องตรงเป๊ะ**

| ไฟล์ในโฟลเดอร์ `src/` | ชื่อใน Apps Script | ชนิด |
|---|---|---|
| [Code.gs](src/Code.gs) | `Code` | Script |
| [Auth.gs](src/Auth.gs) | `Auth` | Script |
| [Data.gs](src/Data.gs) | `Data` | Script |
| [Index.html](src/Index.html) | `Index` | HTML |
| [App.js.html](src/App.js.html) | `App.js` | HTML |
| [Admin.js.html](src/Admin.js.html) | `Admin.js` | HTML |

> ไฟล์ HTML ให้สร้างเป็นชนิด HTML แล้วตั้งชื่อ `App.js` / `Admin.js` (Apps Script เติม `.html` ให้เอง)

**4. รัน `setup()` หนึ่งครั้ง** — เลือกฟังก์ชัน `setup` แล้วกด Run
จะสร้างชีตทั้งหมด ลงข้อมูลตัวอย่าง และล็อกชีตหลักฐานให้

**5. Deploy** — Deploy → New deployment → Web app
- Execute as: **Me** ← **สำคัญ ห้ามเปลี่ยน** (อ่านเหตุผลใน [docs/SETUP.md](docs/SETUP.md))
- Who has access: Anyone / Anyone with Google account ตามนโยบายบริษัท

**6. เปิดลิงก์ `/exec` แล้วตั้ง PIN ให้ตัวเอง** — ผู้ใช้คนแรกคือเจ้าของบัญชี สิทธิ์ผู้ดูแลระบบ

ละเอียดกว่านี้พร้อมภาพประกอบ → **[docs/HOWTO.md](docs/HOWTO.md)**

## ทำให้เป็นของโรงงานคุณ

ทั้งหมดนี้แก้ได้**โดยไม่ต้องแตะโค้ด** หลังติดตั้งเสร็จ

| อยากเปลี่ยน | ทำที่ |
|---|---|
| ชื่อคลัง สกุลเงิน หัว/ท้ายใบเบิก โลโก้ | ชีต `Settings` หรือหน้า **ตั้งค่า → ค่าระบบ** |
| เครื่องจักร / หน่วยงาน | หน้า **ตั้งค่า → เครื่องจักร** |
| หมวดชนิดอะไหล่ (ใช้ออกรหัส) | ชีต `Code_Master` หรือปุ่ม **+ หมวดใหม่** ในหน้าออกรหัส |
| ผู้ใช้และสิทธิ์ | หน้า **ตั้งค่า → ผู้ใช้และสิทธิ์** |
| รูปอะไหล่ | **ตั้งค่า → รูปอะไหล่** ชี้ไปโฟลเดอร์ Drive ที่ตั้งชื่อไฟล์ขึ้นต้นด้วยรหัส |

**ข้อมูลอะไหล่ของคุณเอง** — มี 2 ทาง

1. **ง่ายกว่า:** ลบข้อมูลตัวอย่างใน [`src/Data.gs`](src/Data.gs) ให้เหลือ const ว่าง ๆ
   ติดตั้งแล้วนำเข้าที่ Google Sheets ตรง ๆ (ไฟล์ → นำเข้า → CSV ลงชีต `Parts`)
2. **เหมาะกับหลายโรงงาน:** เขียนข้อมูลลง `src/Data.gs` คั่นคอลัมน์ด้วย `|` ตามหัวข้อที่คอมเมนต์ไว้

`Data.gs` ว่างทั้งไฟล์ก็ติดตั้งได้ ระบบไม่พัง แค่เริ่มจากคลังเปล่า

> **ยอดยกมา** ต้องลงผ่าน `SEED_STOCK` หรือหน้า **รับเข้า** เท่านั้น
> อย่าพิมพ์ตัวเลขคงเหลือลงชีตเอง — เหตุผลอยู่หัวข้อถัดไป

## กฎข้อเดียวที่ห้ามผิด

**ยอดคงเหลือไม่ใช่คอลัมน์** มันคือผลรวม `Qty_Left` ของทุก batch ของอะไหล่ตัวนั้นในชีต `Batches_FIFO`

ที่ออกแบบแบบนี้เพราะทำให้ของพวกนี้ถูกต้องเองโดยไม่ต้องเขียนโค้ดเพิ่ม — FIFO เป็นของจริง,
ต้นทุนแยกตาม batch, ของคืนกลับเข้า batch เดิมที่ออกไป, ของหมดอายุรู้ว่าล็อตไหน

ถ้าพิมพ์ตัวเลขทับในชีต บัญชีกับของจริงจะแยกกันทันทีและไม่มีร่องรอยว่าใครแก้
`setup()` จึง**ล็อก 7 ชีตหลักฐาน**ไว้ให้ (`Batches_FIFO` `Stock_Moves` `Issues` `Blade_Log`
`Audit_Logs` `Ref_Log` `Users`) ส่วนชีตข้อมูลหลัก (`Parts` `Settings` `Code_Master`
`Machines`) ปล่อยให้แก้ในชีตได้ตามปกติ

ปลด/ล็อกกลับได้ที่ **ตั้งค่า → 🔒 ล็อกชีตหลังบ้าน**

## ทดสอบก่อนวางโค้ด

```bash
node tests/run.js
```

7 ชุด รันในหน่วยความจำ **ไม่แตะชีตจริง ไม่ต้องต่อเน็ต ไม่ต้อง deploy**
แก้ `src/` แล้วรันอันนี้ก่อนเสมอ — เทสจะจับได้ถ้าข้อมูลตั้งต้นผิดรูป หรือหน้าจอเรนเดอร์ไม่ครบ

## ข้อจำกัดที่ควรรู้ก่อนตัดสินใจใช้

- **เพดานชีตคือ 10 ล้านช่อง** เมื่อเต็ม **ระบบเบิกและรับเข้าไม่ได้ทั้งหมด** ไม่ใช่แค่ประวัติหาย
  มีหน้าเตือนล่วงหน้าและปุ่มสำรอง-ตัดข้อมูลเก่าให้แล้วที่ **ตั้งค่า → พื้นที่เก็บข้อมูล**
- **สคริปต์รันได้ครั้งละ 6 นาที** คลังใหญ่มาก ๆ บางรายงานจะช้า
- **กล้องสดอาจถูกบล็อก** เพราะแอปรันใน iframe ของ Apps Script ที่เราคุมสิทธิ์ไม่ได้
  (เจอบ่อยใน in-app browser เช่น LINE) ระบบจะถอยไปโหมดถ่ายทีละใบให้เอง
- **การเขียนข้ามหลายชีตไม่ใช่ transaction** ถ้าสคริปต์ตายกลางคัน อาจมีสต๊อกถูกตัดแต่ไม่มีแถวในบัญชีเดินของ
  เกิดยาก แต่ควรรู้ไว้
- **UI เป็นภาษาไทยอย่างเดียว** ข้อความฝังอยู่ในโค้ด ไม่ได้แยกไฟล์ภาษา
