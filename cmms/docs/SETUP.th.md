# ติดตั้ง — ทีละขั้น

[English](SETUP.md) · **ไทย**

ใช้เวลา ~30 นาที · ต้องมีบัญชี Google ของบริษัท (ห้ามใช้บัญชีส่วนตัว — อ่านข้อ 7)

**ก่อนเริ่ม**

```bash
git clone https://github.com/twnote05/Free-CMMS-For-poor-Engineer.git
cd Free-CMMS-For-poor-Engineer/cmms
```

ต้องมี **Node.js 18 ขึ้นไป** ด้วย (ใช้กับ `clasp` และรันเทสต์) — เช็คด้วย `node -v`
ไม่อยากติดตั้งอะไรเลย ข้ามไปอ่านหัวข้อ *ทางเลือกถ้าไม่อยากใช้ clasp* ในข้อ 3 — คัดลอกไฟล์ไปวางเองก็ได้

---

## 1. สร้างไฟล์และโฟลเดอร์

1. สร้าง **Google Sheet** เปล่า 1 ไฟล์ ตั้งชื่ออะไรก็ได้ เช่น `แจ้งซ่อม`
   คัดลอก `SHEET_ID` จาก URL: `docs.google.com/spreadsheets/d/`**`<SHEET_ID>`**`/edit`
2. สร้าง **โฟลเดอร์ใน Drive** สำหรับเก็บรูปที่แนบมากับใบแจ้งซ่อม
   คัดลอก id จาก URL: `drive.google.com/drive/folders/`**`<DRIVE_FOLDER_ID>`**

> วางลิงก์เต็มแทน id ก็ได้ ระบบตัดให้เอง แต่อ่านยากกว่า

---

## 2. สร้างโปรเจค Apps Script

เปิดชีต → **Extensions › Apps Script** → ตั้งชื่อโปรเจค
คัดลอก **Script ID** จาก **Project Settings › IDs**

---

## 3. อัปโหลดโค้ด

```bash
npm i -g @google/clasp
clasp login
```

คัดลอก `.clasp.json.example` เป็น `.clasp.json` แล้วใส่ Script ID ของคุณ:

```json
{ "scriptId": "<SCRIPT_ID ของคุณ>", "rootDir": "gas" }
```

```bash
clasp push -f
```

> ถ้า `clasp push` ไม่ผ่าน ให้เปิด https://script.google.com/home/usersettings แล้วเปิด Apps Script API

**ทางเลือกถ้าไม่อยากใช้ clasp:** เปิดตัวแก้ไข Apps Script แล้วสร้างไฟล์ตามนี้ด้วยมือ คัดลอกเนื้อหาจากโฟลเดอร์ `gas/` ไปวาง — `Code.gs`, `Forms.gs` (ไฟล์สคริปต์) · `index.html`, `app.html`, `styles.html` (ไฟล์ HTML)

---

## 4. ใส่ค่าลับ

**Project Settings › Script Properties › Add script property** ใส่ 4 ตัว:

| ชื่อ | ค่า |
|---|---|
| `SHEET_ID` | จากข้อ 1 |
| `DRIVE_FOLDER_ID` | จากข้อ 1 |
| `DASHBOARD_PASSWORD` | รหัสผ่านเปิดหน้า Dashboard/Export — **ตั้งให้เดายาก อย่าใช้ `1234`** |
| `AUTH_SECRET` | รัน `makeSecret()` (ฟังก์ชันใน `Code.gs` ของชุดนี้ — มีหลังทำข้อ 3 เสร็จ) แล้วคัดลอกค่าจาก Execution log มาวาง |

> ⚠️ **ห้ามเก็บค่าพวกนี้ในชีต `ตั้งค่า`** ที่คนทั้งแผนกเปิดดูได้
> เปลี่ยน `AUTH_SECRET` เมื่อไหร่ ทุกคนหลุดล็อกอินทันที — ตั้งครั้งเดียวแล้วอย่าแตะ

---

## 5. สร้างชีตและงานอัตโนมัติ

ในตัวแก้ไข เลือกฟังก์ชันจากรายการด้านบนแล้วกด **Run**

1. **`setup()`** — สร้างชีตทั้งหมดพร้อมหัวคอลัมน์ และเติมค่าตั้งต้นในชีต `ตั้งค่า` พร้อมคำอธิบายกำกับทุกบรรทัด · รันซ้ำได้ ไม่ลบข้อมูลเดิม
2. **`setupTriggers()`** — ตั้งงานอัตโนมัติ: ต่อตาราง PM 06:00 · สรุปงานค้างให้หัวหน้า 07:00 · เตือนช่าง 08:00

> ⏰ **ตั้งเขตเวลาก่อน** — เวลาเหล่านี้อิงตามเขตเวลาของสคริปต์ ซึ่ง template ตั้งไว้เป็น `Asia/Bangkok` ใน `gas/appsscript.json`
> อยู่คนละเขตเวลาให้แก้ก่อน push หรือแก้ที่ **Project Settings › Time zone** — ไม่งั้นงานยิงผิดเวลา และวันที่ทั้งระบบเพี้ยนหมด

ครั้งแรกที่ Run จะมีหน้าขออนุญาตเข้าถึง Sheets/Drive/Gmail — กดอนุญาต (ขึ้น "Google hasn't verified this app" ให้กด Advanced → Go to ...)

---

## 6. เปิดเป็นเว็บแอป

**Deploy › New deployment › เลือก Web app**

| ช่อง | ค่า |
|---|---|
| Execute as | **Me** |
| Who has access | **Anyone** — ตัวเลือกที่**ไม่**ต้องมีบัญชี Google (UI รุ่นเก่าเขียนว่า *Anyone, even anonymous*) |

กด Deploy แล้วคัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec` — **นี่คือลิงก์ที่จะแจกให้ทุกคน**

> `Anyone` ทำให้ฝ่ายผลิตแจ้งซ่อมได้โดยไม่ต้องมีบัญชี Google
> ทุกอย่างที่ต้องใช้สิทธิ์ถูกกั้นด้วย token ฝั่งเซิร์ฟเวอร์อยู่แล้ว

---

## 7. ใครควรเป็นเจ้าของ

โปรเจคนี้อยู่ใต้บัญชีที่กด Deploy **บัญชีนั้นถูกปิดเมื่อไหร่ เว็บแอปดับทันที และ trigger หยุดทำงาน**

ใช้บัญชีกลางของบริษัท แล้วแชร์สิทธิ์แก้ไขให้ผู้ดูแลอย่างน้อย 2 คน — อย่าใช้บัญชีส่วนตัวของคนที่เขียนโค้ด

---

## 8. ใส่ข้อมูลตั้งต้น

เปิดชีตที่ `setup()` สร้างไว้ แล้วกรอก

### `ทะเบียนเครื่องจักร`

| คอลัมน์ | หมายเหตุ |
|---|---|
| `รหัสเครื่อง` | รหัสภายในของคุณ |
| `ชื่อเครื่องจักร` | **ชื่อหลักที่ใช้ทั้งระบบ** |
| `ประเภท` | เช่น เครื่องจักรหลัก / เครื่องจักรรอง |
| `ผู้ดูแล` | ชื่อสถานี/ทีมที่ดูแล เช่น `EXT` `UV` — **ค่านี้ต้องตรงกับช่อง `สถานีประจำ` ในชีต `Users` เป๊ะ ๆ** |
| `ชื่อเดิมที่เคยใช้` | ชื่ออื่นที่เคยเรียกเครื่องนี้ คั่นด้วย `,` |
| `ใช้งาน` | `ใช่` / `ไม่ใช่` |

> **ช่อง `ชื่อเดิมที่เคยใช้` สำคัญกว่าที่คิด** — ข้อมูลเก่าของโรงงานต้นแบบมีชื่อเครื่องเดียวกันถึง 117 แบบ เพราะทุกคนพิมพ์เอง ใส่ชื่อเก่าไว้ตรงนี้แล้วสถิติจะไม่แตก

### `Users`

| คอลัมน์ | หมายเหตุ |
|---|---|
| `อีเมล` | ใช้ล็อกอิน · **ไม่มีอีเมล = เข้าระบบไม่ได้** |
| `ชื่อ-นามสกุล` | ชื่อที่แสดงบนใบงาน |
| `บทบาท` | `TECH` · `ENG` · `LEAD` · `ADMIN` |
| `ใช้งาน` | `ใช่` / `ไม่` |
| `PIN`, `SALT`, `FAILED`, `LOCKED` | **เว้นว่าง** ระบบเติมเอง |
| `สถานีประจำ` | ตรงกับ `ผู้ดูแล` ในทะเบียนเครื่องจักร หรือ `ALL` = ดูแลทั้งโรงงาน |

ครั้งแรกที่คนหนึ่งล็อกอิน ระบบจะให้ตั้ง PIN เอง (6–8 หลัก) แล้วเก็บเป็น SHA-256 + salt

> ⚠️ **ห้ามสลับลำดับคอลัมน์ที่ 1–9** ถ้าจะเชื่อมกับระบบอื่นที่อ่านชีตนี้ตามตำแหน่ง · คอลัมน์ใหม่ให้ต่อท้ายเสมอ

### `วันหยุด`

วันหยุดของโรงงาน ซึ่งไม่ใช่วันหยุดราชการเสมอไป · ปฏิทิน PM ใช้ชีตนี้เลี่ยงวันที่กางงาน

## 9. ต่อ Google Form (ถ้าจะใช้เช็คชีตประจำวัน)

1. สร้างฟอร์มเช็คชีต แล้วผูกคำตอบลงสเปรดชีต
2. ฟอร์มต้องมีคำถามที่เก็บ **ชื่อเครื่องจักร** และ **ชื่อผู้ตรวจ**
3. ใส่ id ของไฟล์คำตอบเป็น Script Property `CHECK_SHEET_ID`
4. รัน **`sourceAudit()`** — บอกว่าเปิดไฟล์ได้ไหม และชื่อเครื่องในฟอร์มผูกกับทะเบียนติดกี่ตัว

ชื่อหัวคอลัมน์ที่ระบบมองหา แก้ได้ในชีต `ตั้งค่า` (`คอลัมน์เครื่องจักร`, `คอลัมน์ผู้ตรวจ`, `คอลัมน์ผลการตรวจ`)

---

## 10. ตรวจก่อนเปิดใช้จริง

รัน **`dataIssues()`** แล้วอ่าน Execution log — อ่านอย่างเดียว ไม่แก้อะไร

ควรเคลียร์ให้หมดก่อนให้คนเข้าใช้:

- เครื่องจักรไม่มีผู้ดูแล → ไม่มีใครเห็นในโหมด "เครื่องของฉัน"
- สถานีของคนไม่ตรงกับสถานีที่มีเครื่องอยู่จริง → กรองแล้วว่างเปล่า
- `DASHBOARD_PASSWORD` อ่อน
- ผู้ใช้ที่ไม่มีอีเมล

จากนั้นเปิดลิงก์ `/exec` ล็อกอินด้วยบัญชี `LEAD` หนึ่งคน แล้วลองเปิดใบแจ้งซ่อม 1 ใบตั้งแต่ต้นจนปิดงาน
