## `ทะเบียนเครื่องจักร`

`รหัสเครื่อง` · `ชื่อเครื่องจักร` · `ประเภท` · `อาคาร` · `ยี่ห้อ/รุ่น` · `ผู้ให้บริการ` · `ผู้ดูแล` · `ชื่อเดิมที่เคยใช้` · `ใช้งาน`

- `ชื่อเครื่องจักร` คือชื่อหลักที่ทุกหน้าจออ้างถึง
- `ผู้ดูแล` คือชื่อสถานี/ทีม **ต้องสะกดตรงกับ `สถานีประจำ` ในชีต `Users`** — สะกดเพี้ยนตัวเดียวก็เงียบ ไม่มี error · `dataIssues()` จับให้
- `ชื่อเดิมที่เคยใช้` คั่นด้วย `,` ใช้รวมชื่อที่แตกต่างกันให้เป็นเครื่องเดียว

## `แผน PM` — แผนแม่บท

`เครื่องจักร` · `งาน PM` · `รอบ (วัน)` · `ทำครั้งล่าสุด` · `ผู้รับผิดชอบ` · `ใช้งาน` · `ประเภทงาน` · `ชั่วโมงที่วางแผน` · `หัวข้อตรวจ`

ชีตนี้คือ "ควรทำอะไรทุกกี่วัน" — ไม่ใช่ตารางงานจริง

## `ตาราง PM` — ตารางที่กางออกมาแล้ว

`รหัส` · `เครื่องจักร` · `งาน PM` · `วันที่วางแผน` · `วันที่ทำจริง` · `สถานะ` · `ผู้รับผิดชอบ` · `เลขที่ใบแจ้งซ่อม` · `ชดเชยจากวันที่` · `เหตุผลที่เลื่อน` · `หมายเหตุ` · `ประเภทงาน` · `ชั่วโมงที่วางแผน`

ระบบกางให้เองทุกเช้า 06:00 จาก `แผน PM` โดยเลี่ยงวันในชีต `วันหยุด`

## `PM รายเดือน`

ตัวเลขรวมรายเดือนสำหรับ KPI — ชั่วโมงทำงาน แผน PM ที่ตั้งไว้ และที่ทำได้จริง

## `ตั้งค่า`

สองคอลัมน์: `ชื่อค่า` · `ค่า` (+ คำอธิบาย) · `setup()` เติมค่าตั้งต้นพร้อมคำอธิบายทุกบรรทัด

ที่แก้บ่อย: `ชื่อบริษัท` · `SLA วิกฤต/ด่วน/ปกติ/ไม่เร่งด่วน` · `ทำงานวันเสาร์` · `เปิดแจ้งเตือน` · `น้ำหนัก ...` (KPI)

> **ห้ามใส่รหัสผ่านหรือ API key ที่นี่** — ใช้ Script Properties
