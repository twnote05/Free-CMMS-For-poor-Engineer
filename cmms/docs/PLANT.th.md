# ผังโรงงาน — ตั้งค่าให้ตรงกับโรงงานคุณ

[English](PLANT.md) · **ไทย**

หน้าผังโรงงานเป็นกระดานสถานะเครื่องจักรทั้งโรงงานในหน้าเดียว — เขียว เดินอยู่ · แดง หยุดเสีย · เหลือง หยุดตามแผน PM · เทา ยังไม่มีใครบันทึก
เปิดค้างไว้บนจอหน้าโรงงานได้ ไม่ต้องล็อกอิน

**ไม่บังคับ** — ไม่ตั้งค่าก็ใช้ระบบแจ้งซ่อมได้ปกติ เมนู "ผังโรงงาน" จะโผล่ใต้หัวข้อ *ระบบอื่น* เสมอ แต่ถ้ายังไม่ได้วางผังหน้านั้นจะว่าง

## เปิดยังไง

```
https://script.google.com/macros/s/<DEPLOYMENT_ID>/exec?page=plant
```

หรือกดเมนู **ระบบอื่น → ผังโรงงาน** ในหน้าแจ้งซ่อม — แปะลิงก์นี้ลงกลุ่มไลน์หรือทำ QR ติดจอก็ได้

สถานะอ่านจากชีต `บันทึกสถานะเครื่อง` — **ชุดเดียวกับเมนู "งานเครื่องจักร"** ผังไม่ได้เดาสถานะเอง เครื่องที่ยังไม่เคยมีใครบันทึกจะขึ้น "ไม่ทราบสถานะ" ไม่ใช่เขียว

> **ใครเห็นอะไร:** หน้านี้ไม่ต้องล็อกอิน ใครมีลิงก์ก็เห็น **ชื่อเครื่อง กลุ่ม ชื่อเดิม และเดิน/หยุด/ตั้งแต่เมื่อไหร่** — ไม่ส่งสาเหตุที่หยุด ชื่อผู้บันทึก รหัสเครื่อง หรือผู้ดูแลออกไป (ตัดที่ฝั่งเซิร์ฟเวอร์ ใน `apiPlantBoard`)
> ถ้านโยบายโรงงานคุณไม่ให้ชื่อเครื่องออกนอกวง ให้ลบบล็อก `page === 'plant'` ใน `doGet` ของ `Code.gs` และลบ `<a id="navPlant">` ใน `index.html`

การเปลี่ยนสถานะเครื่องจากหน้านี้ต้องล็อกอิน และเป็นเครื่องในสถานีของตัวเอง — ใช้ฟังก์ชันเดิมของระบบ (`apiSetMachineStatus`) ไม่มีทางเขียนใหม่ที่เปิดสาธารณะ

## วางผังของโรงงานคุณ

ไฟล์เดียวที่ต้องแก้คือ **`gas/plant_layout.html`** — ขนาดอาคาร ผนัง ตำแหน่งเครื่อง ห้อง โซน ลำดับการไหล
เอนจินวาดผัง (`gas/plant.html`) เหมือนกันทุกโรงงาน **อัปเกรดทีหลังไม่ทับผังของคุณ** ตราบใดที่ไม่เขียนทับ `plant_layout.html`

ไฟล์ที่ได้มาเป็นโรงงานสมมติ 50 × 30 ม. — แก้ทั้งไฟล์ ไม่ต้องเก็บตัวอย่างไว้

### 1. หน่วยและแกน

เมตรทั้งหมด · `x` ไปทางขวา · `y` ลงล่าง · `(0, 0)` = มุมซ้ายบนของอาคาร (มองจากด้านบน)
เปิดหน้าผังแล้วกดปุ่ม **มุมบน** — มีกริดทุก 10 เมตร ใช้นับตำแหน่งแล้วแก้เลขได้เลย

### 2. ไล่แก้ตามลำดับ

| ตัวแปร | ทำอะไร |
|---|---|
| `BLD_W`, `BLD_H` | กว้าง × ยาวของอาคาร (เมตร) — พื้นและผนังรอบนอกวาดให้เอง |
| `WALLS` | ผนังภายใน `[x1, y1, x2, y2]` ทีละช่วง ช่องประตู = ช่องว่างระหว่างสองเส้น |
| `LAYOUT` | **เครื่องจักร** — ตารางสำคัญที่สุด ดูข้างล่าง |
| `ROOMS` `STORES` `ZONEBOX` | ห้อง · พื้นที่พักของ · กรอบโซน — สี่เหลี่ยมมีชื่อ ไม่มีทรง 3 มิติ |
| `YARDS` | ลานนอกอาคาร (ปั๊มลม คูลลิ่งทาวเวอร์ ห้องกรองน้ำ) |
| `STAGES` | ลำดับการไหลของงาน เรียงตามกระบวนการผลิต ไม่ต้องการก็ใส่ `[]` |

### 3. `LAYOUT` — หนึ่งเครื่องหนึ่งบรรทัด

```js
{ id:"m1", n:"Extruder 1", k:"generic", x:6, y:4, w:7, d:3, h:2.5, grp:"ผลิต" },
```

| ช่อง | ความหมาย |
|---|---|
| `id` | รหัสในผัง ภาษาอังกฤษ ไม่ซ้ำ ตั้งเองได้ |
| `n` | **ชื่อเครื่อง ต้องตรงกับชีต `ทะเบียนเครื่องจักร`** (ชื่อ รหัส หรือชื่อเดิม ตัวใดตัวหนึ่ง ไม่สนตัวเล็กใหญ่ ช่องว่าง `-` `_` `#`) |
| `k` | ชนิดโมเดล — `generic` ใช้ได้กับทุกอย่าง (กล่องเดียว กำหนดขนาดด้วย `w d h`) |
| `x` `y` | มุมซ้ายบนของตัวเครื่อง (เมตร) |
| `alias` | (ไม่บังคับ) ชื่อสำรองที่ทะเบียนอาจสะกดต่างจาก `n` เช่น `alias:["Extrusion 1 - 80","Ext1"]` ลองตามลำดับ แถวทะเบียนหนึ่งแถวจับคู่กับเครื่องในผังได้ตัวเดียว |
| `grp` | ชื่อกลุ่มในรายการทางซ้าย |

ชนิดที่มีโมเดลเฉพาะ (ออกแบบจากโรงงานพลาสติก): `ext` เอ็กซ์ทรูเดอร์ · `uv` สายเคลือบ UV · `cut` ตัด/สล็อต · `xpe` · `mix` เครื่องผสม · `mill` โม่ · `silo` · `cool` คูลลิ่งทาวเวอร์ · `inv` ห้องอินเวอร์เตอร์ · `water` ห้องกรองน้ำ · `comp` ปั๊มลม · `mdb` ตู้ไฟ · `pack` แพ็กกิ้ง
ชื่อชนิดที่พิมพ์ผิดหรือไม่มี → วาดเป็น `generic` ไม่ทำให้หน้าพัง

### 4. ตรวจว่าชื่อตรงกันแล้ว

กล่องเหลืองบนหน้าผัง **"ยังไม่ได้วางตำแหน่งในผัง"** บอกทั้งสองทิศ:
- เครื่องในทะเบียนที่ไม่มีตำแหน่งในผัง → เพิ่มลง `LAYOUT`
- เครื่องในผังที่ไม่มีในทะเบียน (ขึ้น "ไม่ทราบสถานะ") → แก้ `n` ให้ตรง หรือใส่ชื่อนั้นเป็น *ชื่อเดิม* ในทะเบียน

### 5. ตรวจไฟล์ก่อน deploy

```bash
node test.js
```

ตรวจว่า `id` ไม่ซ้ำ · ขั้นตอนใน `STAGES` อ้างเครื่องที่มีจริง · กรอบทุกอันมี `x0<x1` `y0<y1` — พิมพ์ตกหรือสะกดผิดจะฟ้องตรงนี้ ไม่ใช่ตอนหน้าผังว่างหลัง deploy

## หาพิกัดจากแปลน CAD (ถ้ามี)

ถ้ามีแปลนโรงงานเป็นไฟล์ CAD ไม่ต้องวัดเอง — เซฟเป็น **DXF** (ASCII) แล้วใช้ `tools/dxf_labels.py` ดึงป้ายชื่อทุกป้ายพร้อมพิกัดเป็นเมตร:

```bash
python tools/dxf_labels.py แปลน.dxf --origin 100000 50000 --scale 0.001
python tools/dxf_labels.py แปลน.dxf --origin 100000 50000 --scale 0.001 --grep "mix|pack|cool"
```

- `--origin X Y` = พิกัดใน DXF ของ **มุมซ้ายบนของอาคาร** (เปิดใน CAD อ่านพิกัดมุมนั้น) — กลายเป็น `(0, 0)` ของผัง
- `--scale` = หน่วย DXF เป็นเมตร (มิลลิเมตร `0.001` · เซนติเมตร `0.01`)
- ผลลัพธ์ `x  y  ข้อความ` คัดลอกลง `LAYOUT` ได้เลย

**ตรวจจุดอ้างอิงก่อนเชื่อ:** ป้ายเส้นบอกระยะความกว้างอาคารต้องตกกลางผนังด้านนั้น ถ้าเลื่อน แปลว่า `--origin` ผิด
ป้ายที่ซ่อนอยู่ในบล็อก (BLOCK) จะไม่ขึ้น — ใน CAD ให้ Explode บล็อกนั้นก่อนเซฟ DXF

อ่านแล้วจะได้พิกัดของ **ป้าย** ไม่ใช่พิกัดตัวเครื่อง ป้ายมักอยู่ใกล้ตัวเครื่องแต่ไม่ใช่มุมซ้ายบนพอดี — ดูผลในโหมด **มุมบน** แล้วขยับเลขทีละนิด
