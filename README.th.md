# ระบบแจ้งซ่อมบำรุง (CMMS) สำหรับโรงงานเล็ก

[English](README.md) · **ไทย**

ระบบแจ้งซ่อม + PM + เช็คชีตประจำวัน + KPI ที่รันบน **Google Sheets + Apps Script** ล้วน ๆ
ไม่มีเซิร์ฟเวอร์ ไม่มีค่ารายเดือน ไม่ต้องมีฝ่าย IT

> สร้างให้โรงงานพื้น UPVC/SPC ~50 คน ใช้งานจริงอยู่ทุกวัน
> ตัดข้อมูลบริษัทออกหมดแล้ว เหลือแต่โครงให้เอาไปตั้งของตัวเอง

---

## ทำไมถึงเป็นแบบนี้

โรงงานเล็กไม่มีงบคลาวด์ ไม่มีคนดูแลถ้าคนทำลาออก และคนใช้งานคือช่างที่ยืนอยู่หน้าเครื่องจักร มือเปื้อนน้ำมัน ถือมือถือ Android ราคาประหยัด **งบฝึกอบรมคือ 5 นาทีต่อคน**

ข้อจำกัดพวกนี้ตัดทางเลือกออกเกือบหมด สิ่งที่เหลือคือ:

- **ข้อมูลอยู่ในชีต ไม่ได้อยู่ในโค้ด** — โค้ดพังทั้งหมด เปิดชีตทำงานต่อด้วยมือได้ทันที
- **Google Form เป็นที่กรอก CMMS เป็นที่อ่าน** — ฟอร์มทำงานบนมือถือได้ดี อัปโหลดรูปได้ คนคุ้นอยู่แล้ว ไม่ต้องสร้างหน้ากรอกแข่งกับมัน
- **คนที่ไม่ใช่โปรแกรมเมอร์ต้องแก้เองได้** — SLA, น้ำหนัก KPI, ชื่อเครื่องจักร, วันหยุด อยู่ในชีตทั้งหมด

## มีอะไรบ้าง

| | |
|---|---|
| **ใบแจ้งซ่อม** | ฝ่ายผลิตแจ้งได้โดยไม่ต้องล็อกอิน · มอบหมายได้หลายคน · จัดการทีละหลายใบ · ถังขยะ (ยกเลิกโดยไม่ลบข้อมูล) · ยกระดับอัตโนมัติเมื่อเลยกำหนด · ส่งซ่อมภายนอก/ส่งเคลม · พิมพ์ PDF |
| **PM** | แผนรายปี กางตารางอัตโนมัติ · ปฏิทินที่เลี่ยงวันหยุดโรงงาน · ใบงาน PM · รายงานสรุปรายเดือน |
| **เช็คชีตประจำวัน** | อ่านคำตอบจาก Google Form โดยตรง · คะแนนรายเครื่อง · กดดูข้อที่ไม่ผ่าน · เปิดใบแจ้งซ่อมจากข้อที่ตกได้เลย |
| **พารามิเตอร์เครื่องจักร** | อ่านค่าที่ช่างบันทึก เทียบกับพิกัด · วิศวกรกดรับรอง · ตัวสร้าง Google Form อัตโนมัติจากทะเบียนเครื่อง |
| **KPI** | MTTR · %Breakdown · ซ่อมซ้ำ · คะแนนช่างรายคนแบบถ่วงน้ำหนัก (น้ำหนักแก้ได้ในชีต) |
| **อื่น ๆ** | โหมดมืด · ไทย/อังกฤษ · QR ติดเครื่องจักร · ไทม์ไลน์ย้อนเหตุการณ์ · กระดิ่งแจ้งเตือน · Audit log |

**สิทธิ์:** `TECH` → `ENG`/`LEAD` → `ADMIN` ตรวจที่ฝั่งเซิร์ฟเวอร์ทุกครั้ง ไม่ใช่แค่ซ่อนปุ่ม
ล็อกอินด้วย **อีเมล + PIN** ไม่ใช่ Google OAuth เพราะช่างยืมมือถือกันใช้และหลายคนไม่มีบัญชีบริษัท

## ติดตั้ง

ใช้เวลาประมาณ 30 นาที → [คู่มือติดตั้งแบบละเอียด](docs/SETUP.th.md)

```bash
npm i -g @google/clasp && clasp login
cp .clasp.json.example .clasp.json     # ใส่ scriptId ของคุณ
clasp push -f
```

จากนั้นในตัวแก้ไข Apps Script:

1. **Project Settings › Script Properties** ใส่ 4 ค่า: `SHEET_ID`, `DRIVE_FOLDER_ID`, `DASHBOARD_PASSWORD`, `AUTH_SECRET`
2. รัน `setup()` — สร้างชีตและหัวคอลัมน์ให้ครบ พร้อมค่าตั้งต้นที่มีคำอธิบายกำกับ
3. รัน `setupTriggers()` — ตั้งงานอัตโนมัติรายวัน
4. **Deploy › New deployment › Web app** · Execute as: **Me** · Who has access: **Anyone**

## ตั้งค่าให้เป็นของบริษัทคุณ

ส่วนใหญ่แก้ในชีต ไม่ต้องแตะโค้ด

| อยากเปลี่ยน | แก้ที่ |
|---|---|
| ชื่อบริษัทบนหัว PDF | ชีต `ตั้งค่า` → `ชื่อบริษัท` |
| SLA, เวลาเตือน, วันทำงานเสาร์ | ชีต `ตั้งค่า` |
| น้ำหนักคะแนน KPI | ชีต `ตั้งค่า` (เป็นนโยบาย ไม่ใช่ตรรกะ) |
| เครื่องจักรและผู้ดูแล | ชีต `ทะเบียนเครื่องจักร` |
| ผู้ใช้และสิทธิ์ | ชีต `Users` |
| วันหยุดโรงงาน | ชีต `วันหยุด` |
| **โลโก้** | `gas/index.html` — สลับ data URI ในแท็ก `<img>` |
| **สีแบรนด์** | `gas/styles.html` บรรทัดบนสุด |
| **เขตเวลา** | `gas/appsscript.json` — มาเป็น `Asia/Bangkok` แก้ก่อน push ครั้งแรก |
| **ชื่อสถานี/แผนก** | ไม่ต้องแก้โค้ด — ระบบอ่านจากช่อง `ผู้ดูแล` ในทะเบียนเครื่องจักรเอง |

**ภาษา:** UI เป็นไทย สตริงอยู่ในโค้ดโดยตรง ปุ่มสลับอังกฤษใช้ตารางคำแปลใน `gas/app.html`

## ทดสอบ

```bash
node test.js
```

ชุดทดสอบ ~2,800 บรรทัด ไม่ใช้ framework ไม่ต่อเน็ต ไม่แตะ Apps Script จริง
**ต้องขึ้น `OK — ผ่านทั้งหมด` ก่อน deploy เสมอ**

## รู้ไว้ก่อนเอาไปใช้

- **อ่านก่อนเชื่อ:** `clasp push` ขึ้นโค้ดใหม่ แต่ลิงก์ที่คนใช้ยังชี้เวอร์ชันเดิม ต้อง `clasp deploy` ด้วย — ดู [RUNBOOK](docs/RUNBOOK.th.md)
- **หลังแก้ชีต ต้องรัน `clearCache()`** ไม่งั้นหน้าจอยังเห็นของเก่าไปอีก 5 นาที
- **`dataIssues()`** คือตัวตรวจคุณภาพข้อมูล รันได้ตลอด อ่านอย่างเดียว — เครื่องไม่มีผู้ดูแล ช่องเช็คลิสต์ไม่มีชื่อ ค่าพิกัดน่าสงสัย รหัสผ่านอ่อน
- **ข้อจำกัด Apps Script:** 6 นาทีต่อการรัน 1 ครั้ง · 10 ล้านเซลล์ต่อไฟล์ · `CacheService` ไม่รับประกัน TTL
- **เว็บแอปเปิดสาธารณะ (`ANYONE_ANONYMOUS`)** เพื่อให้ฝ่ายผลิตแจ้งซ่อมโดยไม่ต้องล็อกอิน → **โค้ดฝั่งเซิร์ฟเวอร์คือด่านความปลอดภัยเดียวที่มี**

## สิ่งที่ยังไม่มี

ถ้าคุณต้องการของพวกนี้ ต้องเขียนเพิ่มเอง: เชื่อมสต็อกอะไหล่ · ต้นทุนค่าแรง · ลายเซ็นดิจิทัล · แอปมือถือ · ระบบ staging แยก · กันกดซ้ำตอนเน็ตหลุด
