# ระบบซ่อมบำรุงฟรี สำหรับวิศวกรงบน้อย

[English](README.md) · **ไทย**

ระบบงานซ่อมบำรุงสำหรับโรงงานเล็ก 2 ตัว รันบน **Google Sheets + Apps Script** ล้วน ๆ
ไม่มีเซิร์ฟเวอร์ ไม่มีค่ารายเดือน ไม่ต้องมีฝ่าย IT

ทั้งคู่ใช้งานจริงอยู่ทุกวันในโรงงานพื้น UPVC/SPC ~50 คน · ตัดข้อมูลบริษัทออกหมดแล้ว เหลือแต่โครงให้เอาไปตั้งของตัวเอง

| | ทำอะไร | สถานะ |
|---|---|---|
| **[cmms/](cmms/)** | ใบแจ้งซ่อม · PM · เช็คชีตประจำวัน · พารามิเตอร์เครื่องจักร · KPI | พร้อมใช้ |
| **stock/** | อะไหล่ เครื่องมือ ใบมีด — ตัดสต็อกแบบ FIFO รู้ต้นทุนจริงรายครั้ง | กำลังจัดไฟล์ |

เลือกใช้ตัวเดียวหรือสองตัวก็ได้ · เป็น **คนละ Apps Script project** แต่ละตัวมี `.clasp.json` และ deployment ของตัวเอง
สิ่งเดียวที่ใช้ร่วมกันคือชีต `Users` — ถ้าจะใช้ทั้งคู่ **อ่าน [SHARED-USERS.md](SHARED-USERS.md) ก่อน**

## ทำไมถึงเป็นแบบนี้

โรงงานเล็กไม่มีงบคลาวด์ ไม่มีคนดูแลถ้าคนทำลาออก และคนใช้งานคือช่างที่ยืนอยู่หน้าเครื่องจักร มือเปื้อนน้ำมัน ถือมือถือ Android ราคาประหยัด **งบฝึกอบรมคือ 5 นาทีต่อคน**

ข้อจำกัดพวกนี้เหลือทางเลือกไม่กี่ทาง:

- **ข้อมูลอยู่ในชีต ไม่ได้อยู่ในโค้ด** — โค้ดพังทั้งหมด เปิดชีตทำงานต่อด้วยมือได้ทันที
- **Google Form เป็นที่กรอก ตัวระบบเป็นที่อ่าน** — ฟอร์มทำงานบนมือถือได้ดี อัปโหลดรูปได้ คนคุ้นอยู่แล้ว
- **คนที่ไม่ใช่โปรแกรมเมอร์ต้องแก้เองได้** — SLA, น้ำหนัก KPI, ทะเบียนเครื่องจักร, วันหยุด อยู่ในชีตทั้งหมด
- **ซ่อนปุ่มไม่ใช่การจำกัดสิทธิ์** — ตรวจบทบาทที่ฝั่งเซิร์ฟเวอร์ทุกครั้ง
