# RUNBOOK — ตัวสร้างเอกสารโรงงาน

คู่มือคนดูแล · อ่านตอนมีปัญหา
วิธีใช้งานทั่วไปดู [README.th.md](README.th.md)

> ตัวนี้ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล ไม่มี deployment
> **มันคือไฟล์ HTML ไฟล์เดียว** ปัญหาส่วนใหญ่จึงเป็นเรื่องเบราว์เซอร์ ไม่ใช่เรื่องระบบ

---

## 1. ข้อมูลอยู่ไหน

| เก็บที่ | มีอะไร | หายเมื่อไหร่ |
|---|---|---|
| **`localStorage` ของเบราว์เซอร์** | โลโก้บริษัท (`wi_logo`) · ไอคอน PPE (`wi_ppe_lib`) · ธีมสว่าง/มืด (`wi_theme`) | ล้าง browsing data · ใช้โหมดไม่ระบุตัวตน · เปลี่ยนเครื่อง · เปลี่ยนเบราว์เซอร์ |
| **ไฟล์ที่ Export** | เอกสารที่สร้างเสร็จ | ตามที่เก็บไฟล์เอง |
| **`WI_Generator.html`** | ค่าตั้งต้นในบล็อก `CONFIG` | ตามไฟล์ |

> ⚠️ **เนื้อหาที่กรอกในฟอร์มไม่ได้ถูกบันทึกไว้** ปิดแท็บแล้วหาย
> ต้อง Export หรือ Print ออกมาก่อนปิดเสมอ · นี่คือข้อจำกัดที่ต้องบอกคนใช้ตั้งแต่วันแรก

**ย้ายเครื่อง** — โลโก้กับไอคอน PPE ไม่ตามไปด้วย ต้องอัปโหลดใหม่ในเครื่องใหม่
ถ้าอยากให้ติดไปกับไฟล์เลย ให้ฝังเป็น base64 ใน `CONFIG` แทนการอัปโหลด

---

## 2. ขึ้นเวอร์ชันใหม่

ไม่มี deploy — **แจกไฟล์ใหม่ทับของเดิม**

```bash
node wi_test.js
```

ต้องได้ `ผ่านทั้งหมด` ถ้าไม่ผ่าน อย่าแจก

จากนั้นส่ง `WI_Generator.html` ให้คนที่ใช้ หรือบอกให้โหลดใหม่จาก repo

> คนที่เคยอัปโหลดโลโก้ไว้แล้ว **ไม่ต้องทำใหม่** เพราะโลโก้อยู่ใน `localStorage` ของเบราว์เซอร์ ไม่ได้อยู่ในไฟล์

---

## 3. ย้อนกลับเมื่อเวอร์ชันใหม่มีปัญหา

เก็บไฟล์เวอร์ชันเก่าไว้ แล้วเอากลับมาใช้ — จบ

ถ้าโหลดจาก repo:

```bash
git log --oneline -- WI_Generator.html     # ดูประวัติไฟล์
git checkout <commit> -- WI_Generator.html
```

เอกสารที่ Export ไปแล้วไม่กระทบ เพราะเป็นไฟล์ที่แยกออกไปแล้ว

---

## 4. แก้ค่าตั้งต้นให้ทั้งโรงงาน

เปิด `WI_Generator.html` ด้วย Notepad หรือ VS Code → หา `const CONFIG` ใกล้ ๆ บนสุด

แก้เลขที่เอกสาร ชื่อแผนก ผู้รับผิดชอบ ฯลฯ แล้วแจกไฟล์ใหม่
**คนใช้ไม่ต้องมากรอกค่าเดิมซ้ำทุกครั้ง**

> แก้แล้วเปิดไฟล์ทดสอบหนึ่งรอบก่อนแจก — พิมพ์ผิดในบล็อกนี้ทำให้หน้าเว็บไม่ขึ้นเลย
> ถ้าหน้าขาว กด F12 ดู Console จะบอกบรรทัดที่พัง

---

## 5. อาการเสียที่เจอบ่อย

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| เปิดแล้วหน้าขาว | เบราว์เซอร์เก่าเกินไป หรือ `CONFIG` พิมพ์ผิด | ใช้ Chrome/Edge รุ่นปัจจุบัน · กด F12 ดู Console |
| Export Excel ไม่ได้ | ครั้งแรกต้องต่อเน็ตเพื่อโหลด ExcelJS จาก CDN | ต่อเน็ตหนึ่งครั้ง หรือดูข้อ 6 |
| โลโก้หาย | ล้าง browsing data หรือเปิดโหมดไม่ระบุตัวตน | อัปโหลดใหม่ · ถ้าหายบ่อย ให้ฝังใน `CONFIG` |
| สั่งพิมพ์แล้วขอบเพี้ยน | เบราว์เซอร์ตั้งขนาดกระดาษไม่ตรง | ในหน้าต่าง Print เลือก A4 หรือ A3 ให้ตรงกับที่เอกสารออกแบบไว้ และตั้ง Margins เป็น Default |
| ป้ายความปลอดภัยใน Excel หน้าตาไม่เหมือนในจอ | ที่ออกมาเป็น *ทะเบียนป้าย* ไว้แก้ข้อความ ไม่ใช่ตัวป้าย | พิมพ์ป้ายจริงจากเบราว์เซอร์ สัดส่วนตรง ISO 3864 มากกว่า |
| เปิดในแอป LINE แล้วเพี้ยน | เว็บวิวในแอปไม่ใช่เบราว์เซอร์เต็ม | เปิดด้วย Chrome |

## 6. ใช้แบบออฟไลน์ล้วน

ทุกอย่างทำงานในเครื่องอยู่แล้ว **ยกเว้น Export Excel** ที่ดึง ExcelJS จาก CDN ครั้งแรก

ถ้าโรงงานไม่มีเน็ตเลย: โหลด `exceljs.min.js` มาเก็บไว้ข้าง ๆ ไฟล์ แล้วแก้แท็ก `<script>` ให้ชี้ไฟล์ในเครื่องแทน URL ของ CDN

สั่งพิมพ์ทำงานออฟไลน์ได้อยู่แล้ว ไม่ต้องแก้อะไร

---

## 7. เรื่องที่ต้องระวัง

**ตาราง FMEA AP** — ตารางที่เป็นทางการอยู่ในคู่มือ AIAG-VDA ซึ่งมีลิขสิทธิ์ และแหล่งสาธารณะให้ตัวเลขไม่ตรงกัน
ตารางในไฟล์นี้เป็นชุดที่สอดคล้องกันเอง (เพิ่ม S, O หรือ D แล้วลำดับความสำคัญไม่มีทางลดลง)

**ตรวจกับฉบับที่โรงงานคุณถือสิทธิ์ก่อนใช้งานจริง** ถ้าต่างกัน แก้ที่ `AP_TABLE` ในไฟล์ จุดเดียวจบ

**สูตรคำนวณอื่น ๆ** — ตรวจกับมาตรฐานที่หน่วยงานคุณใช้ก่อนเอาไปอ้างอิงในเอกสารที่ต้องผ่านผู้ตรวจ
